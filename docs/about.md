Festival Season Network is a **coordination library**, not an event owner. We publish shared tools, honest season data, and design constraints any organizer can fork — seeded in Greater Sacramento, usable anywhere.

## Values

- **Share the playbook** — open-source methods beat reinventing the flyer stack every year
- **Honest scale** — claim what you can measure; log gaps instead of inventing attendance
- **Season over single events** — warm-ups feed a capstone; don’t fight sister hosts for the same crowd
- **Stakeholders can return** — vendors, sponsors, and partners should be able to say yes next year

## Principles (P1–P4)

The working design constraints behind those values:

| Principle | Question |
|-----------|----------|
| **P1** Roll-up calendar | When? |
| **P2** Group attendance | Who shows up? |
| **P3** Right-sizing | How big? |
| **P4** Stakeholder sustainability | Who else wins? |
